*Example code from the "Repetition is bad" talk at Voxxed, 18/04/15.*



## Build and run

Requires JDK 11+ and Maven 3.6+.

```bash
mvn package          # builds target/Voxxed-repetition.war
mvn tomee:run        # starts TomEE Plus 8 (Java EE 8) with the app deployed
```
